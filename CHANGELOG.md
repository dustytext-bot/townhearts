## pub-1.0 (hybrid migration — the clean public repo is born) — 2026-10-06

Tag: `pub-1.0`. The publication contract is **`public-3`** (publisher `pub-1.0`).

This repository is the clean public tree of the TownHearts hybrid migration: the site, the published data, the scoring reference, the publication guards, docs, and explicit licenses (MIT site code / CC BY-NC 4.0 data, owner-confirmed 2026-10-06) — while the production collector, database, opt-out list, graph artifacts, backups, and raw collect machinery moved OUT of any git repository (private/proprietary; see PRIVACY.md and the sections below).

- **Data: `public-3` — pair-level aggregates only.** Replaces the old graph format. **Kept:** warmth, tier, `co_loc_weight`, co_locations, growth_7d / growth_30d, shared_days, recent_shared_samples_30d, largest_shared_group, common_places, roster (muses), index / index_names, freshness + scoring + socialites meta (schema_version `public-3`, publisher_version `pub-1.0` added). **Removed:** per-event arrays (`flows[]` / `directed[]`), speech previews, transaction reasons, per-event amounts, exact event timestamps, exact first/last-seen instants (→ plain `first_seen_date` / `last_seen_date`), `places_present`, and the raw layers. Interaction context is now aggregate counts: `context: {directed_count, reciprocal_directed, flow_count, mb_flow_total}`.
- **Scoring unchanged.** co-presence-2 (warmth = Σ 2/(n−1)), tier floors 2/6/14/30, the Socialites rule — all identical; published here as a standalone, self-testing copy: `reference/scoring_reference.py` (the repo's tests pin it in lockstep with `zone_rules.js` and the published data).
- **Site: evidence displays only.** The pair-evidence panel now renders aggregate summaries (Public directed interaction / Public Musebuck activity / Observation evidence + the warmth-and-tier line); every event-array/preview/reason/amount/exact-timestamp render path is removed; date-level rendering for first/last seen; stale-banner + freshness behavior unchanged (keys off `meta.sampled_at`, partial notice owner-suppressed). Structure, rankings, socialite treatment, animation, branding, filters, and visual identity are preserved.
- **Publication guards ship in this repo** (`scripts/`): `validate_public_output.py` (public-3 schema + semantics), `scan_public_output.py` (file allowlist + SQLite magic + forbidden keys + private paths), `check_repo.py` (a strict repo-file allowlist). CI (`.github/workflows/ci.yml`) runs the public pytest suite, every node harness, and the validator + scan + allowlist job on every push/PR — public CI is self-contained and sees only this tree.
- **Docs rewritten for public-3:** `muse.txt` (the repo's own agent spec — kept/removed fields, aggregates only, the reference scorer, no SQL recipes), `API.md` (jq/curl recipes over `graph.json`; the db/SQL recipes and per-event docs are gone), `README.md`, and the new `PRIVACY.md` (public-data-only statement, aggregate-only publication, the private pre-publication opt-out, forward-only semantics with the honest note that past aggregates remain).
