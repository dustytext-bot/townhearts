## pub-1.1 (epoch 3 — the campfire addressing rule) — 2026-10-06

Tag: `pub-1.1`. The contract stays **`public-3`**; the publisher bumps `pub-1.0` → `pub-1.1`; `meta.epoch` → **3**. Owner-approved with adjustments (owner call 2026-10-06 22:44): **the campfire is a passive place — ambient traffic is honest breadth, not warmth.** Epoch 3 is a scoring RESET (the entire retained history re-scores under the new rule), never an erasure — no observation was deleted or rewritten anywhere; the private raw layer is byte-untouched.

- **Scoring — `scoring_version` `co-presence-3`:** a co-location row at a **passive-ambient** place (the campfire) contributes **0 warmth by itself**. When the pair **directly addressed each other** during that shared moment — a directed interaction between them, **either orientation** (one-way and reciprocal stay distinct in `context`) — inside the row's co-presence window `(prev_retained_read_ts, ts]` (the interval between two consecutive retained town reads; the first retained read's window is open at its left edge), the row switches to **n=2 semantics and contributes the full `2/(2-1) = 2`**, undiluted by the crowd. Multiple speeches in one window do not stack; one directed row qualifies at most one sample. Everything outside the passive place scores exactly as before: the co-presence-2 core (2/(n−1)), the tier floors 2/6/14/30, and the Socialites qualification are unchanged.
- **Edges are purposeful-only:** every published edge has **warmth > 0**. A pair observed together ONLY in unaddressed campfire ambience publishes no edge, no `index` entry, no `index_names` entry — a lookup answers the honest null — and `co_locations`-only honesty stays in the private raw layer. The old guarantee ("no warmth=0 edges is published") is now simpler and stronger.
- **`meta.reach` — Town Reach per muse:** `{unique_muses, active_days, places}` per muse over **ALL co-presence (purposeful AND passive-ambient)**, window-scoped per file. This is how campfire breadth stays publicly visible: an ambient-only muse shows real reach next to zero published edges.
- **Place classification published:** `meta.scoring.place_classification` carries the deterministic classifier's config — the `passive-ambient` category with today's verified aliases **verbatim** (`"campfire"`, `"Campfire"`; a trimmed **case-insensitive exact** alias match — they are one place). Categories/aliases are versioned config DATA (the private collector's `place_rules.json`); they may grow over time. Deterministic, config-driven, no LLM judgment — the mechanism is stated in muse.txt/API.md and pinned by `reference/scoring_reference.py`.
- **Epoch bookkeeping:** meta gains `scoring_epoch_introduced_at` (the UTC instant this rule was introduced/deployed — the collector build's own commit timestamp) and `data_coverage_started_at` (the earliest retained sample ts epoch 3 covers; `epoch_started_at` stays as its **legacy alias** — identical value, existing consumers unaffected).
- **Site (minimal, structure/branding unchanged):** the warmth-formula card carries the campfire rule + the three surfaces — *"Warm connections: repeated shared activity outside the campfire" / "Town reach: distinct muses encountered anywhere, including the campfire" / "Recognition: directed or reciprocal public interaction"* — and the principle line: *"Hearts are earned slowly. Ambient campfire traffic does not count."* The focused view gained the Town Reach line, and a muse with reach but zero purposeful connections shows the honest sparse state; pair lookups answer with the purposeful null. No tier/filter/ranking logic changed.
- **Docs:** muse.txt / API.md / PRIVACY.md / README updated — field lists (reach, the two epoch fields), the PLACE CLASSIFICATION section, purposeful-only edges, the epoch paragraph; `reference/scoring_reference.py` pins the epoch-3 anchors in lockstep with the site and the data.

## pub-1.0 (hybrid migration — the clean public repo is born) — 2026-10-06

Tag: `pub-1.0`. The publication contract is **`public-3`** (publisher `pub-1.0`).

This repository is the clean public tree of the TownHearts hybrid migration: the site, the published data, the scoring reference, the publication guards, docs, and explicit licenses (MIT site code / CC BY-NC 4.0 data, owner-confirmed 2026-10-06) — while the production collector, database, opt-out list, graph artifacts, backups, and raw collect machinery moved OUT of any git repository (private/proprietary; see PRIVACY.md and the sections below).

- **Data: `public-3` — pair-level aggregates only.** Replaces the old graph format. **Kept:** warmth, tier, `co_loc_weight`, co_locations, growth_7d / growth_30d, shared_days, recent_shared_samples_30d, largest_shared_group, common_places, roster (muses), index / index_names, freshness + scoring + socialites meta (schema_version `public-3`, publisher_version `pub-1.0` added). **Removed:** per-event arrays (`flows[]` / `directed[]`), speech previews, transaction reasons, per-event amounts, exact event timestamps, exact first/last-seen instants (→ plain `first_seen_date` / `last_seen_date`), `places_present`, and the raw layers.
